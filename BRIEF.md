# Supervisor Snapshot – Dashboard Brief

## Summary

A single-page dashboard for a supervisor at a non-profit community mental health organization in Philadelphia. The dashboard serves as a "Monday Morning Snapshot" providing at-a-glance visibility into client risk, team capacity, and organizational impact. The primary user is a supervisor managing 5 caseworkers who serve individuals receiving mental health benefits through Medicaid across multiple neighborhood sites.

**Primary Goal:** Help me understand my team's workload, needs in the community, and potential risks.

**Dashboard Name:** Supervisor Snapshot

---

## Tech

- **Framework:** Vue 3 + Vuetify 3 (TypeScript)
- **Charting:** Chart.js via vue-chartjs
- **Data:** Mock data in a local JSON file (generated by Copilot)
- **Responsive:** Desktop + mobile friendly (mobile stacks vertically)
- **Accessibility:** WCAG AA compliant
- **Hosting:** Vercel
- **Auth:** None required for prototype

## Data

### Mock Dataset

Generate a local JSON file with ~50-60 clients across 5 caseworkers. Each caseworker is assigned to multiple sites.

### Caseworkers

Elly, Orien, Kirsten, Mac, Charlotte

### Neighborhoods (6)

Kensington, North Philadelphia, West Philadelphia, Center City, South Philadelphia, Germantown

### Referral Sources (5)

Hospital, PCP, Self-Referral, Crisis Team, Court System

### Care Types (5)

Individual Therapy, Substance Use Treatment, Crisis Stabilization, Medication Management, Case Management

### Sites/Providers (~15)

Generate ~15 fictional site/provider names (e.g., "Kensington Community Health Center", "West Philadelphia Behavioral Health Clinic", etc.). Each caseworker is assigned to multiple sites.

### Client Fields

Each client record should include:

| Field | Type | Notes |
|---|---|---|
| clientId | string | Unique identifier |
| clientName | string | Full name |
| assignedCaseworker | string | One of the 5 caseworkers |
| site | string | One of the ~15 sites |
| neighborhood | string | One of the 6 neighborhoods |
| referralSource | string | One of the 5 referral sources |
| referralDate | date | Date of referral |
| firstAppointmentDate | date or null | Null for waitlisted clients |
| careTypeNeeded | string | One of the 5 care types |
| clientStatus | string | "active", "waitlisted", or "closed" |
| lastContactDate | date | Last date caseworker contacted client |
| medicaidExpirationDate | date | Medicaid coverage expiration |
| providerName | string | Mental health provider or PCP name |

### Dashboard Metrics

**🔴 Action Needed (Tile counts with expandable client lists):**

- Clients not contacted in 30+ days
- Clients with Medicaid expiring in next 30 days
- Current waitlist count (with trend vs. prior month)

**🟡 Team & Capacity (Bar chart + trend arrows):**

- Active caseload per caseworker
- New referrals this month vs. prior month

**🟢 Big Picture (Large number tiles with trend lines):**

- Total individuals actively served
- Average days from referral to first appointment

**📊 Charts/Graphs:**

- Average days from referral to first appointment (single number tile + trend line)
- Referrals by neighborhood (horizontal bar chart)
- Sites/providers serving the most individuals (horizontal bar chart, responds to global filters)
- Care needs by neighborhood (stacked bar chart, shows all neighborhoods by default, responds to global filters)

## Interactions

### Global Filters

All global filters affect every section on the dashboard, including the 🔴 Action Needed tiles.

| Filter | Type | Default |
|---|---|---|
| Neighborhood | Multi-select | All selected |
| Date Range | Month/Year to Month/Year | Last 30 days |
| Caseworker | Multi-select | All selected |
| Reset/Clear Filters | Button | Resets all filters to defaults |

### 🔴 Action Needed Expandable Panels

Each tile is clickable and reveals an expandable panel that slides open below the tile with a client list.

**Not Contacted 30+:**

| Client Name | Caseworker | Last Contact Date | Neighborhood | Days Since Contact |
|---|---|---|---|---|

**Medicaid Expiring in 30 Days:**

| Client Name | Caseworker | Expiration Date | Days Until Expiration |
|---|---|---|---|

**Waitlist (includes total count at top of panel):**

| Client Name | Referral Date | Days Waiting | Neighborhood | Care Type Needed |
|---|---|---|---|---|

### Charts

- Hover tooltips showing exact values on all charts
- No click-through interactions on charts for now

## Style

### Design Aesthetic

Clean, modern, card-based layout. Generous white space, subtle elevation/shadows instead of hard borders, rounded corners on all cards and components. Include gradients and modern UI elements. 

### Mode

Light mode only.

### Font

Roboto (Vuetify default).

### Brand Colors

| Token | Hex | Usage |
|---|---|---|
| Primary Purple 100 | `#6b297d` | Primary actions, headers|
| Primary Purple 80 | `#6a0c7d` | Hover states, emphasis |
| Primary Purple 30 | `#c977b1` | Secondary chart colors, light accents |
| Secondary Green 100 | `#285707` | Positive trends, ↑ arrows |
| Secondary Green 10 | `#e7ffde` | Positive trend backgrounds, subtle highlights |
| Neutral White | `#ffffff` | Card backgrounds, page background |
| Neutral Light Gray | `#f5f5f5` | Page background, alternating table rows |
| Neutral Mid Gray | `#e0e0e0` | Dividers, subtle borders |
| Neutral Dark Gray | `#212121` | Primary text |

Include complementary teriarty colors to support graphs and charts

### Status Colors

| Status | Color | Usage |
|---|---|---|
| 🔴 Action Needed | Red/coral | Tile accents, alert counts |
| 🟡 Team Capacity | Amber | Trend indicators, capacity warnings |
| 🟢 Positive / Big Picture | Secondary Green 100 (`#285707`) | Positive trends, ↑ arrows |

### Component Styles

- **Cards:** White background, subtle box-shadow, rounded corners (8px), no hard borders
- **Metric Tiles:** Large bold numbers, percentage change with colored arrows (↑↓) comparing to prior period
- **Tables (expandable panels):** Clean rows, alternating subtle gray backgrounds for readability
- **Charts:** Complementary tertiary colors for graphs and bar charts. Secondary Green for positive indicators, muted/soft tones for chart fills

### Accessibility (WCAG AA)

- All color combinations must meet AA contrast ratios
- Use `aria-labels` on all interactive elements, charts, and filters
- Keyboard navigable filters and expandable panels
- Screen reader friendly chart descriptions
